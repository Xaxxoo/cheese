What changes in PinPad.tsx

  • Remove w-full max-w-[264px] on the grid — buttons expand to fill the screen width (pages already have px-4 padding)
  • Change Button shape: rounded-2xl (square) → rounded-full (circle), matching OPay's style
  • Change Number size: text-2xl → text-3xl — scales with the bigger circular button
  • Change Grid gap: gap-4 → gap-[14px] — a bit more air between circles
  • Change Active press: adds a gold ring (ring-2 ring-[#d4a843]/20) on active:scale-90 instead of just scale
  • Change Dot indicator gap: gap-3 → gap-4, dots slightly larger w-3.5 h-3.5
  • Add Gold glow on filled dots: shadow-[0_0_10px_rgba(212,168,67,0.5)]
  • Add Delete icon: size={20} → size={24} — proportional to larger button
